# YTuner - Müzik Akort Uygulaması

Profesyonel, hızlı ve hassas bir müzik akort uygulaması. Gitar, Bass, Ukulele gibi standart enstrümanların yanı sıra Türk müziği için mikrotonal (koma) desteği sunar.

## Özellikler
- **Hassas Akort:** Yüksek doğruluklu frekans analizi.
- **Enstrüman Seçenekleri:** Gitar (6-7 tel), Bass (4-7 tel) ve Ukulele için hazır modlar.
- **Mikrotonal Desteği:** Türk müziği perdeleri ve koma değerleri gösterimi.
- **PWA Desteği:** Telefonunuza uygulama olarak kurulabilir.
- **Farklı Temalar:** Kömür, Krem, Mor Neon ve Orman temaları ile kişiselleştirilebilir arayüz.

## Kurulum ve Kullanım
Uygulamayı GitHub üzerinden canlı olarak kullanmak için:
1. GitHub deposuna gidin.
2. **Settings** (Ayarlar) sekmesine tıklayın.
3. Sol menüden **Pages** seçeneğine gidin.
4. **Build and deployment** bölümünde Source olarak "Deploy from a branch" seçili olduğundan emin olun.
5. Branch olarak `main` (veya dosyanızın olduğu dalı) ve klasör olarak `/ (root)` seçip **Save** butonuna basın.
6. Birkaç dakika içinde uygulamanızın linki üst kısımda görünecektir.
